# Cartographie Dynamique ArcGis Online

Premier projet de cartographie dynamique, elle s'appuie sur la conception d'un site internet annexe d'un parc naturel régional et de la création de StoryMaps et de cartographies dynamiques par l'interface ArcGis Online.

Accès au site web hébergé en ligne : https://loic-spadi.github.io/carto-dynamique-agol/

Ce dépôt contient :
  - Les différentes pages du site internet, des fonts et des images utilisées pour la création du site
  - Une vidéo de présentation des StoryMaps dans le cas où les services AGOL sont inactives
